# AI chats

Put the full chat history for this task in this folder before the repo is pushed.

- Cursor: `cursor_session.txt` is the transcript copied while the script was being written. Replace it with a fresh export of the whole chat before you push, so later turns are included. Do not include inline autocomplete.
- ChatGPT, Claude, or Gemini: put the Share links in `links.txt`.
- Delete nothing except passwords and API tokens, which should be replaced with `[REMOVED]`.

The Hugging Face token and any Kaggle credential must not appear in these files.
